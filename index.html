Card Purity Mode lock the selected card as the only primary card identity

Addition-only Card Purity: locks the prompt so the selected rank + suit stays the only primary playable-card identity in the image. Nothing from the existing generator was removed or replaced.
Default is Clean Main Card Only. Switch to Decorative Suits if you want suit motifs in the background, or Support Cards if you want matched-suit support cards.

How Card Purity works

  • Clean Main Card Only: no held cards, no inset mini-cards, no alternate rank or suit cards, no prop cards with different labels.
  • Main Card + Decorative Suits: decorative suit symbols and background motifs are allowed, but no second printed playing card.
  • Main Card + Support Cards: support cards allowed only if they match the selected suit and stay visually secondary.
  • Duo mode always keeps both main cards on the same selected rank + suit.
